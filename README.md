A program that writes one funny one-line review a dog gives the mailman to `/output/entry.txt` for the The Dog Reviews the Mailman bounty on make.fun.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
